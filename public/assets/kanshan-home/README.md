# 看山·愿望寄存处：首页视觉素材说明

## 文件用途

- `home-reference-original.png`：用户确认的首页定稿。正式首页直接使用它保持完整构图，只叠加必要的真实控件与局部遮罩。
- `home-reference-adjusted-preview.png`：早期沟通预览，不作为当前实现依据。
- `home-background.webp`：早期分层方案的纯背景图，当前首页不使用，保留供后续页面设计参考。
- `home-background-source.png`：纯背景的高质量 PNG 源文件，供后续裁切或重新压缩。
- `liu-kanshan-wave-transparent.png`：透明背景的刘看山挥手角色素材，用于网页独立定位和响应式缩放。

## 当前网页实现

为最大程度保持定稿画面，标题、刘看山、对话框、表单外观和“我的愿望”卡片外观均保留在定稿图中。网页只叠加以下内容：

1. 可输入的商品名称输入框；
2. 覆盖蓝色按钮的真实提交热区；
3. 覆盖“我的愿望”卡片的真实入口热区；
4. 用于移除 `0/30` 与手机系统手势条的局部遮罩；
5. 实际渲染不低于 14px 的辅助文案。

其他流程可以继续使用 `liu-kanshan-wave-transparent.png` 作为独立角色素材。

## 已确认的首页规则

- 商品输入框不显示 `0/30` 或其他字符计数。
- `我的愿望`副标题保持静态文案：`查看你寄存的愿望清单`，不增加动态统计。
- 不绘制手机系统底部黑色手势条。
- 输入框提示文字颜色沿用设计稿观感，不额外加深。
- `先了解一下，再决定也没关系哦`实际渲染字号不得低于 `14px`。
- 页面和项目文档中的产品名后续统一为：`看山·愿望寄存处`。
- 首页按定稿的 560×1184 比例随手机宽度等比缩放；输入框、提交按钮和愿望入口必须保持可操作，且不得产生横向溢出。
