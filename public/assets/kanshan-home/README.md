# 看山·愿望寄存处：首页视觉素材说明

## 文件用途

- `home-reference-original.png`：用户确认的首页原始设计稿，作为构图、色彩和整体氛围的主要视觉基准。
- `home-reference-adjusted-preview.png`：按本轮反馈移除字符计数和系统手势条、放大辅助文案后的效果预览。该文件只用于沟通，不应作为网页整页背景。
- `home-background.webp`：正式页面优先使用的纯背景图，已移除角色与前景交互组件。
- `home-background-source.png`：纯背景的高质量 PNG 源文件，供后续裁切或重新压缩。
- `liu-kanshan-wave-transparent.png`：透明背景的刘看山挥手角色素材，用于网页独立定位和响应式缩放。

## 网页图层要求

以下内容必须使用 HTML/CSS 实现，不得烘焙进背景图：

1. 产品标题：`看山·愿望寄存处`
2. 刘看山角色
3. 对话框及文案：`告诉我你想买的好物吧`
4. 商品名称输入框和提交按钮
5. 辅助文案：`先了解一下，再决定也没关系哦`
6. `我的愿望`入口卡片

推荐层级从后到前为：背景图 → 刘看山 → 对话框 → 表单 → 我的愿望入口。

## 已确认的首页规则

- 商品输入框不显示 `0/30` 或其他字符计数。
- `我的愿望`副标题保持静态文案：`查看你寄存的愿望清单`，不增加动态统计。
- 不绘制手机系统底部黑色手势条。
- 输入框提示文字颜色沿用设计稿观感，不额外加深。
- `先了解一下，再决定也没关系哦`实际渲染字号不得低于 `14px`。
- 页面和项目文档中的产品名后续统一为：`看山·愿望寄存处`。
- 页面应按手机宽度响应式布局，不能依赖固定高度或整页图片缩放；微信内打开并弹出软键盘后，输入框和主按钮仍应可见、可操作。
